# aside/

Nothing here is part of the current pipeline. Kept for reference only.

- `exp0X_superseded/` - training scripts and drivers from experiments 01-07,
  plus the exp08-era drivers (`run_all.py`, `seed_eval.py`), the twitch-era
  plotting script (`evaluation.py`), `data_analysis.py`, and the old `notes.md`.
  They import from the project root, so they no longer run from this folder.
- `results_old/` - twitch results, the pre-exp08 hyperparameter searches, the
  overfit check, and the LaTeX build of the exp08 summary (the PDF also lives in
  `results/exp08/`).
- `plots_old/` - twitch analysis figures and the old loss-decay curves.
- `slides/` - presentations.
- loose scripts (`plot_data_dist.py`, `sanity_check_features.py`,
  `verify_signal.py`, `constants_best_for_twitch.py`) - one-off checks.
