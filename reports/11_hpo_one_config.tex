\textbf{The configuration.} One model for all 8 datasets: inside and outside edges get two
separate colors (their own weights in the GNN), trained with GLASS's recipe on GLASS's splits.
On the synthetic datasets every shared node is replaced by one copy per subgraph. The real
datasets run without copies, because their copies graphs do not fit in GPU memory.

\textbf{What we ran}, per dataset:
\begin{enumerate}
  \item An Optuna search over aggregation, pooling, hidden size, layers, lr, dropouts, batch
        size, weight decay, norm, jumping knowledge, head, and (synthetic only) edge counts.
        Each trial is 3 seeds, scored by mean validation. Trials: hpo\_neuro 80, hpo\_metab and
        em\_user 160, the rest 300. Weak trials were stopped after seed 0.
  \item The 3 best trials on 10 seeds. The one with the best 10-seed validation is reported.
        Test was never used to choose.
\end{enumerate}

\section*{Findings}
\begin{itemize}
  \item \textbf{Best on 3 of 4 synthetic datasets.} density 98.9 (GPEN 95.6), cut\_ratio 95.2
        (GPEN 93.6), component 100. coreness is 0.9 below GPEN and 2.7 above GLASS.
  \item \textbf{The search fixed cut\_ratio and density.} Against report 10: cut\_ratio +6.1,
        density +4.1, with smaller spread between seeds.
  \item \textbf{Worse on the real datasets, except em\_user.} Against report 10: ppi\_bp $-4.6$,
        hpo\_neuro $-5.0$, hpo\_metab $-0.6$. em\_user rose by 9.8 but is still 5.9 below GLASS.
  \item \textbf{On ppi\_bp, validation chose the worst finalist.} It scored 71.8 on validation
        and 55.3 on test. The other two finalists scored 70.2 on validation and 59.4 and 59.3 on
        test.
  \item \textbf{On hpo\_neuro, validation is below test.} All 3 finalists score about 58 on
        validation and 64 on test. This dataset had the smallest search (80 trials).
  \item \textbf{On em\_user, validation hardly predicts test.} Over all trials, the correlation
        between validation and test is 0.22 (0.74 to 0.98 on the other datasets, except ppi\_bp
        at 0.56). The 3 finalists have almost the same validation (80.6 to 81.0) but test 79.8 to
        85.5.
\end{itemize}
